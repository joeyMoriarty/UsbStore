Chip health –
This is the chip's own die temperature. The warmest part of the board is usually the voltage regulator, which this sensor can't see. The test runs the real overheat sequence — drives unmounted, USB suspended, WiFi off, light sleep — for 30 s, so the board is offline for about a minute and then restarts.
Firmware –
Use build/usbstore.bin. No need to unplug the hub. The new version runs on probation for a minute: if it crashes first, the board goes back to this version on its own.
